# Setup

## Requirements

Node.js 20+, pnpm, PostgreSQL 13+, and Redis.

```bash
pnpm install
pnpm migration:run
pnpm start:dev
```

Seed data is optional and already-present seed users are not regenerated by the application. `pnpm seed` is development-only and requires `SEED_PASSWORD`.

## Environment

Required: `DATABASE_URL`, `REDIS_URL`, `COOKIE_SECRET` and `OTP_HMAC_SECRET` (32+ characters), plus `CORS_ORIGINS` containing `https://www.snzeshi.tech`.

Email uses Resend:

```dotenv
MAIL_TRANSPORT=resend
MAIL_FROM="SecureByPay <no-reply@verified-domain>"
RESEND_API_KEY=re_...
MAIL_TEMPLATE_SIGNUP_OTP=tmpl_...
MAIL_TEMPLATE_PASSWORD_RESET=tmpl_...
```

`MAIL_TRANSPORT=console` can print OTPs during local development. OTP is used only for signup verification and password reset; login uses email and password.

## Production

```bash
pnpm build
pnpm migration:run
pnpm start:prod
```

Use `MAIL_TRANSPORT=resend`, HTTPS, the Resend settings, `CORS_ORIGINS=https://www.snzeshi.tech`, and `SWAGGER_ENABLED=true` for assessment access to `/docs`.

## Checks

```bash
pnpm test
```

API documentation: `https://<api-host>/docs` in production or `http://localhost:3000/docs` locally.
